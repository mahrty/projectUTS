Program Studi

Empat program studi di Jurusan Teknik Komputer dan Informatika, Politeknik Negeri Medan.

D3

Teknik Komputer

Lama studi 3 tahun (6 semester)

Fokus pada sistem komputer, jaringan, dan perangkat keras dan lunak untuk kebutuhan industri.

Bidang Kajian

  • Sistem komputer
  • Jaringan komputer
  • Perangkat keras dan lunak

Prospek Karier

  • Teknisi jaringan komputer
  • Administrator sistem
  • Teknisi perangkat keras
D3

Manajemen Informatika

Lama studi 3 tahun (6 semester)

Fokus pada pengembangan peran sistem informasi, dan teknologi digital terkini.

Bidang Kajian

  • Sistem informasi
  • Basis data
  • Teknologi digital terkini

Prospek Karier

  • Staf sistem informasi
  • Pengelola basis data
  • Operator dan analis data
D4

Teknologi Rekayasa Perangkat Lunak

Lama studi 4 tahun (8 semester)

Fokus pada pengembangan perangkat lunak, dan teknologi digital terkini.

Bidang Kajian

  • Pengembangan perangkat lunak
  • Rekayasa perangkat lunak
  • Teknologi digital terkini

Prospek Karier

  • Web dan mobile developer
  • Software tester

Teknologi Rekayasa Multimedia Grafis

Prospek Karier
